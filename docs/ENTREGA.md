## Empaquetado

Crear el paquete únicamente después de cerrar los bloqueos de VALIDACION_FINAL.md. Incluir código fuente, contratos y documentación. Excluir node_modules, target, dist, builds Godot, cachés, resultados temporales, .env, .secrets y credenciales. Mantener las carpetas Git anidadas si la entrega requiere historial; para código fuente limpio puede exportarse un zip de la raíz con filtros explícitos.

El paquete final no se genera en esta etapa porque la matriz todavía contiene HU parciales/faltantes. Los commits son responsabilidad del usuario, según su instrucción.
