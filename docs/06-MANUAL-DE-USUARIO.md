# Manual de usuario

## HU-01: Inicio de sesión

1. Abrir el cliente Godot.
2. Elegir iniciar sesión.
3. Completar el código de dispositivo en el navegador.
4. Configurar o validar TOTP.

## HU-02 a HU-06: Biblioteca y tablero

Buscar un caso en la biblioteca, revisar pistas y abrir el tablero. Los personajes pueden arrastrarse o seleccionarse con clic y luego colocarse en una casilla. Las casillas bloqueadas no permiten movimiento.

## HU-07 a HU-09: Mecánicas

Agregar notas a candidatos, eliminar marcas y solicitar pistas progresivas. Las reglas rápidas deben permanecer visibles.

## HU-10: Contrarreloj

Crear una partida contrarreloj y observar el temporizador. El juego impide enviar solución después de finalizar el tiempo.

## HU-11 a HU-13: Versus

Crear o unirse a una sala, observar el progreso del rival con polling y enviar la solución para determinar ganador.

## HU-14 a HU-16: Perfil

Consultar perfil, XP, nivel, estadísticas y logros desbloqueados.

## HU-17 a HU-18: Ranking e historial

Consultar ranking global e historial personal.

## HU-19: Tutorial

Desde el menú o tablero abrir Tutorial. El tutorial explica arrastre, clic, notas, pistas y validación.

## HU-20: Idioma

Cambiar entre español e inglés desde la configuración. Las etiquetas usan traducciones `tr()`.

## HU-21: Accesibilidad y salida

Usar botones de volver, cancelar y salir. Una partida activa solicita confirmación antes de abandonar.
